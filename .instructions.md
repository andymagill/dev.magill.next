# GitHub Copilot Instructions for dev.magill.next

## Package Management

- **Always use `pnpm`** for all package management tasks (install, add, remove, etc.)
- Never use `npm` or `yarn`
- The project enforces pnpm 10.25.0 via the `packageManager` field in package.json

## Before Committing

**Must complete these steps before suggesting git commits:**

0. **If package.json or pnpm-lock.yaml were modified**: `pnpm install`
   - Run this first if dependencies were added or changed
   - Ensures lock file is in sync with package.json

1. **Type check**: Verify TypeScript compilation passes (part of build)
   - Type safety is critical - TypeScript errors block Cloudflare deployments
   - Run `pnpm run build` which includes: `Running TypeScript ...`

2. **Run linting and formatting**: `pnpm run lint` and `pnpm run fix`
   - Enforce code style consistency (ESLint + Prettier)
   - Fix formatting automatically
   - Ensure no linting errors remain (lint uses `--max-warnings=0`)

3. **Run tests**: `pnpm run test`
   - Verify all tests pass
   - Catch any regressions introduced by changes
   - Test mocks must match Post interface exactly (9 required properties)

4. **Full build validation**: `pnpm run build`
   - Ensures TypeScript compilation passes
   - Verifies Next.js build succeeds
   - Confirms static site generation and sitemap generation work

5. **Verify**: `git status` should show clean working tree before committing

## Key Commands Reference

- `pnpm install` - Install dependencies (runs husky setup via prepare script)
- `pnpm run dev` - Start development server
- `pnpm run build` - Production build + sitemap generation
- `pnpm run test` - Run Vitest suite
- `pnpm run lint` - Check for linting errors (fails on warnings)
- `pnpm run fix` - Auto-fix ESLint and formatting issues
